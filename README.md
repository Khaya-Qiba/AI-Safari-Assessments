 # Savannah Tracker Initiative
This repository contains the Savannah Tracker Report: Precision Prompting Initiative.
The report outlines how precision prompting can improve maternal health support in rural Kenya and Uganda.
## Purpose
The project demonstrates how AI prompts can be rewritten to provide culturally suitable, logistics-aware, and safe guidance for mothers living far from clinics.
## Contents
- Nutrition Advice Prompt
- Appointment Reminder Prompt
- Emergency Triage Prompt
- Reflection on precision prompting in rural maternal care
## Usage
The report can be used as a reference for designing AI systems that act as practical partners in healthcare.
Researchers, developers, and community health workers can adapt the prompts to local needs.
