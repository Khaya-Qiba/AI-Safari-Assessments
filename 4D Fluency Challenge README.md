# EduSavvy 4D Fluency Challenge
This repository contains redesigned AI learning assistant interactions using the 4D Fluency Framework from the Tsavo Adventure.  
The interactions are tailored for secondary students across East Africa, aligned with Kenya CBC and Uganda PLE curricula.
## Purpose
The project demonstrates how AI prompts can be localized to provide culturally relevant, curriculum-aligned, and accessible learning support.  
It addresses issues of generic Western examples, overly complex language, and lack of communal learning context.
## Contents
- Interaction A: Science Tutoring (Photosynthesis)  
- Interaction B: Math Homework Help (Algebra)  
- Interaction C: Parent Progress Report  
## Features
- Delegation, Description, Discernment, Agency, and Diligence principles applied  
- Low temperature settings for factual consistency  
- RAG safeguards linking to KICD and EduSavvy databases  
- Negative prompting to avoid irrelevant or culturally mismatched references  
## Usage
The redesigned interactions can be used as templates for configuring EduSavvy’s AI assistant.  
Developers can adapt the prompts directly into the system to ensure localized and effective student support.
